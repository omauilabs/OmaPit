# OmaRide hardware brief — user supplied

- Ariel Rider Grizzly V2, modified.
- 72 V system; two separate batteries.
- Newer battery and Grin Technologies motor controllers; controller models not yet identified.
- One latest-version Cycle Analyst shared across both batteries; exact firmware/model identifier not provided.
- Physical three-way drive selector: front only / both / rear only.

Design must distinguish measured total values from unavailable per-pack/per-motor data. Do not assume one shared Cycle Analyst provides independently measured telemetry for both batteries or reports the physical switch position. Electrical topology and available interfaces need verification before a live adapter.
