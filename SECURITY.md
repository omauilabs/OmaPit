# Security

OmaPit runs locally. The parts that can be reached from other machines are the optional companion server in LAN mode (token-protected) and the outbound Home Assistant, MQTT and ntfy connections you configure. See [INTEGRATIONS.md](INTEGRATIONS.md).

## Reporting a vulnerability

Please report privately: on GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue or include exploit details anywhere public.

Include the OmaPit version or commit, which component is affected and how to reproduce it. Leave out real tokens, passwords and personal cook data.

OmaPit is maintained by volunteers, so there is no guaranteed response time. Fixes go into the next release, and the release notes credit the reporter unless you ask otherwise.

## Supported versions

Only the latest release and `main` receive fixes.
